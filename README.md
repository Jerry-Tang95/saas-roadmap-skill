# SaaS创业路线图2.0 · Agent Skill

> 吴昊《SaaS创业路线图2.0：to B企业的创新与精细经营》蒸馏出的 AI Agent Skill。
> 26 张能力卡 + 1 个来源路由入口，按用户意图加载，适用于 WorkBuddy / CodeBuddy / Claude 等 Skill 框架。

**这个 skill 不教你"什么是 SaaS"，它替你做判据。** 它把这本带财务模型的经营手册，拆成 26 个"有门槛数字、有否决条件"的决策卡。你问"我们能不能扩销售团队"，它不会给你励志话术，它会要你的三级毛利数据。

---

## 30 秒验证装没装好

装好后直接问这一句：

> **我们 SaaS 产品客单价 4 万，能不能开始加销售？**

期望行为：路由到 `sales-team-margin-gate`，**先向你要数据**（月度营收、销售团队成本、市场成本、当期服务成本、人均产出、有没有 SOP），而不是直接回答"可以/不可以"。

如果它开始讲通用管理学、或直接给结论 —— 没装好，或触发词被更大范围的知识覆盖了。

## 26 张能力卡（全部摊开，不挑拣）

SKILL.md 的路由表按「用户意图」索引。下列**全部 26 张**都在这一个包里，没有隐藏项。

共 26 张：**6 张 critical · 12 张 high · 8 张 medium**。

### critical（6 张 · 遇到就该先查）

| 能力卡 | 触发提问 | 卡里给什么 |
|---|---|---|
| `strict-pmf-gate` | 判断产品有没有达到 PMF；该不该开始规模化投放 | ICP 内活跃健康 >70% + 累计 200 万/10 客户，**两条同时成立**才算 |
| `sales-team-margin-gate` | 能不能扩销售团队；营销飞轮财务上转不转得起来 | 三级毛利门槛（销售成本 / +市场 / +服务），只能覆盖第一级就停止扩张 |
| `renewal-rate-first-metric` | 资源该给产研还是客户成功；公司最重要的指标是什么 | 续费率是第一指标，40 年 NPV 模型下每 1% 影响公司价值 5～17 倍 |
| `saas-cost-structure` | 一单合同到底赚不赚钱；为什么首年必然亏损 | 双链路：新购利润贡献约 10%，续费+增购约 60% |
| `business-finance-pnl` | 怎么把业务数据和财务数据打通；费用怎么分摊才不失真 | 业财一体损益表 G/P/EBIT 三层 + 按工时（非产出）分摊 + 决策实验 |
| `human-efficiency-as-strategy` | 这个定制项目接不接；要不要做 PaaS / 找代理商 | 人效是战略**自变量**：先定目标，再由目标倒推生态位与业务边界 |

### high（12 张）

| 能力卡 | 触发提问 |
|---|---|
| `acv-determines-everything` | 客单价变了组织架构要怎么改；该不该设 SDR / 直销还是 KA |
| `renewal-rate-vs-ndr` | 续费率和 NDR 不一样该怎么办；金额续费率怎么算；多年单会不会污染指标 |
| `cac-payback-over-ltv-cac` | LTV/CAC 达标但回收期很长还能不能投；怎么降获客成本 |
| `winter-resource-priority` | 钱不多了先投哪里；要不要裁员；现金要留几个月 |
| `no-sop-no-scaling` | 先冲规模还是先补 SOP；销售打法怎么沉淀 |
| `hiring-threshold-by-efficiency` | A / B 团队下月各招几个人；要不要继续招销售 |
| `renewal-upsell-ownership` | 这单业绩算销售还是客户成功；销售和 CSM 打架怎么定 |
| `customer-health-metrics` | 怎么提前判断客户会不会续费；活跃度指标怎么定；北极星指标怎么找 |
| `pricing-is-positioning` | 竞品降价要不要跟；折扣怎么管；产品怎么定价 / 分版本 |
| `annual-plan-breakdown` | 明年营收目标定多少合理；年度规划怎么做；目标怎么拆到部门 |
| `say-no-to-all-in-one` | 大客户要我们做新模块接不接；要不要做一站式解决方案 |
| `multi-year-contract-trap` | 客户愿意一次付 3 年费打 7 折，收不收；多年单该怎么管 |

### medium（8 张）

| 能力卡 | 触发提问 |
|---|---|
| `conservative-valuation` | 两份 TS 选高估值还是低估值；下一轮估值怎么谈 |
| `csm-kpi-stages` | 客户成功部 KPI 怎么定；CSM 该考核续费金额还是活跃度 |
| `no-free-main-product` | 要不要出免费版；PLG 能不能在中国做 |
| `flat-commission-not-tiered` | 提成方案怎么设计；阶梯提成好不好；怎么让销售冲刺 |
| `org-design-seven-layers` | 换系统能解决协作问题吗；部门扯皮怎么归因；组织架构怎么设计 |
| `subsidized-expansion-trap` | 首年不赚钱靠第二年续费赚回来行不行；能不能跨越式发展 |
| `metric-objectivity` | 续费率口径该不该剔除倒闭客户；部门 KPI 怎么设才客观 |
| `strong-incentive-strong-control` | 搞 PK 赛只考核拜访量行不行；高激励怎么配套管控 |

## 什么情况下不该用它

负面用例不是"答不上来"，而是**有更专业的入口**。这本书的边界很清楚：

| 你的问题 | 为什么不该用这个 skill |
|---|---|
| C 端增长、投放、社群/私域运营 | 全书只研究 to B。"加个会员体系提升 LTV"这类问题它没有素材 |
| 通用管理学、领导力、个人职业规划 | 终章的"道—法—术—势"属信念层，作者自己也没给可执行步骤，本 skill 已标记为不可 skill 化 |
| 2024 年之后的估值锚、AI Native 产品形态 | 书成于 2022 年底。PS 倍数（A 轮 30 / B 轮 20 / C 轮 15 / 上市 12）**2026 年不可直接引用** |
| 具体软件的技术架构、数据库、研发工程实践 | 全书不涉及技术选型 |
| **客单价低于 20 万 / 小微市场 / 垂直小市场** | ⚠️ 这是最要命的一条：作者自己承认"客单价 20 万元以下的公司续费增购商务费用会非常小"，却没给这类公司一套对应模型。**样本是"高客单价 + 大客户 + 有 PaaS"的头部通用工具 SaaS** |
| 医疗 / 政务等强合规行业的经营决策 | SKILL.md 已内置提醒：本书不覆盖强合规行业的特殊约束 |

另外，**给不出关键输入数据时它会追问而非硬答**：客单价中位数、毛利结构（主营成本占比 / CAC 占比）、续费率与 NDR、人效、现金月数 —— 这五个数字缺一个，书里大多数判据就跑不动。这是设计如此，不是缺陷。

## 这本书不能全信的部分（本 skill 已内建这些提醒）

一个有立场的蒸馏包，应该把原书的软肋一起交出来。以下 8 条来自 `references/overview.md` 的批判章节：

1. **资本周期预测已失效** —— 作者预期 2024 回暖、2025 开启 IPO。实际未按此节奏。PS 数字不可用，但"中位数营收 × 保守倍数"的方法仍成立。
2. **AI 判断部分被证伪** —— 书中断言"LLM 短期（10 年计）难有完整人类智慧""AI 之间难以主动协作""GPT 写 Python 但不能自动调试"，后两条已被推理模型与多 Agent 协作推翻。作者自设有效期 5 年。
3. **全部人力成本参数是 AI 之前的量级** —— 研发费用占 ARR 25%～40%、服务成本占 ARR 15%～25%、平均人效 30 万元。AI 辅助研发与 AI 客服普及后，这些区间很可能整体下移。
4. **按坐席订阅的定价地基正在被侵蚀** —— 全书增购逻辑默认"加坐席"，而 outcome-based / consumption-based 定价正在兴起。
5. **样本高度集中于"自己人"** —— 成功案例几乎全部来自作者投资 / 顾问 / 陪跑圈，存在幸存者偏差与"CEO 自述"偏差。
6. **关键数字多为个人估计** —— 西方经验有效比例约 70%、网络效应需占 30% 节点、CAC 占首单 40%～100%、续费成本 20%～30%，均无样本量与方法。**本 skill 要求引用时标注「作者估计」**。
7. **"续费率最重要"是自我指涉的论证** —— ONPV 模型最强的假设恰是"续费率第 5 年起 80% 并保持 40 年"，而这正是中国 SaaS 最弱的一项。模型越证明续费重要，越说明它对输入值敏感。
8. **商业 SaaS 的合规风险几乎没讨论** —— 支付合规（二清）、数据授权与个人信息保护、金融牌照、垫资现金流风险基本缺失。在《数据安全法》《个人信息保护法》已实施的背景下，这是商业模式论证最薄弱的一环。

## 数字判据速查（判断这个 skill 值不值得装）

用来感受一下它的颗粒度 —— 全是"能给数字就不给形容词"的判据：

| 判据 | 数值 |
|---|---|
| 严格 PMF | ICP 内活跃健康 >70%；ICP 内累计 >200 万、>10 客户；一般 ≥18 个月 |
| 新购 vs 续费利润贡献 | 10% vs 60% |
| 主营业务成本 / CAC | 约占 ARR 20% / 约占首单 70%（区间 40%～100%） |
| 续费率估值弹性 | 每 1% → 5～17 倍（产研/服务/折扣率约 2.6 倍） |
| 折扣杠杆 | 9 折 → 利润 −42.5%；7 折 → 利润为负 |
| 客单价分界线 | 2 万（电销/面销、设 SDR）、10 万（促活责任人）、200 万/年（回到 AM 制） |
| 增购归属 | 签约后 6 个月为界（前归销售、后归 CSM） |
| CSM 容量 | ARR 200 万～500 万元/人 |
| 现金红线 | 18～24 个月 |
| 寒冬融资门槛 | NDR >90% |
| 人效基准 | 中国 SaaS 平均约 30 万元/人，头部 40–80 万元 |

> 以上除个别来自上市公司财报外，绝大多数为**作者估计**或小样本观察，用时请自行校准。
