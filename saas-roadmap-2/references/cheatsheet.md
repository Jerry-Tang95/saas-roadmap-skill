# 决策规则速查 — SaaS创业路线图2.0：to B企业的创新与精细经营

| 能力 | 一句话规则 |
|---|---|
| 严格 PMF 标准：ICP 内活跃健康 >70% + 累计 200 万/10 客户 | 先用 ICP 内健康度否决营收——活跃健康比例不过 70%，销售额再多也不算 PMF |
| 销售团队三级毛利门槛：能不能继续扩团队 | 月度营收只能覆盖销售团队成本就停止扩张，先提人均月单产出 |
| 客单价决定论：营销/销售/交付/服务/促活全链路匹配 | 客单价中位数定死整套打法：2 万元以下是集客+电销，交接次数呈高台跳水形 |
| 续费率与 NDR 的双指标分工及背离诊断 | NDR 看客户价值增减给投资人，续费率看服务执行给 CSM；两者可严重背离（67% vs 200%） |
| SaaS 的本质是续费：续费率是第一指标（估值弹性 5～17 倍） | 续费率每变 1% 影响公司价值 5～17 倍，远超产研/服务/折扣率的约 2.6 倍 |
| SaaS 成本结构双链路：新购利润贡献 10% vs 续费增购 60% | 首单不赚钱是结构性的：ARR 扣 20% 主营成本再扣 70% CAC，只剩 10% 利润贡献 |
| 业财一体损益表：G/P/EBIT 三层 + 按工时分摊 + 决策实验 | 用 G=R−C、P=G−CAC、EBIT=P−FF 三层表把经营决策变成可算的实验 |
| 资本寒冬用 CAC Payback 替代 LTV/CAC 做主判据 | 钱多久回来比 LTV/CAC 是否大于 3 更重要；控制 CAC 靠提人效而不是降提成 |
| 人效即战略：人效目标 → 生态位 → 自研/合作/组织决策 | 先定人效目标再倒推做法——80 万人效的公司不该接 30 万的定制项目 |
| 资本寒冬资源投放优先级 + 现金跑道 + 化有形裁员为无形 | 只有 100 万先投服务部；产研排最后，因为多投 100 万需销售多做 500 万相抵 |
| 稳健估值：按营收中位数 × 保守 PS，不按高目标估值 | 用中位数营收 × 10 倍 PS 估值，别把高目标当基准——高估值是定时炸弹 |
| 无标准、不复制 / 无文字，不管理 | 没有 SOP 不许扩团队；标准化要提前到只有几人时，60 分就先用起来 |
| 人效阈值决定能否继续扩招 | 设一个绝对人效阈值当扩招开关（含新人），低于就先提人效不许招 |
| 客户价值链条职责划分：续费归 CSM，增购以 6 个月为界 | 新购归销售、续费一律归 CSM、增购以签约后 6 个月为界；销售不拿续费业绩 |
| 活跃度 → 健康度 → 北极星指标的三层指标体系 | 定义活跃度的目的不是衡量使用，而是预测续费率——统计单元必须是能做出续费决策的主体 |
| 客户成功三阶段 KPI 演化与优秀团队五要素 | 早期反而先考核短期业绩筛人，沉淀期转活跃率，复制期才取消短期营收考核 |
| 定价即定位：价格位不可逆 + 折扣杠杆 + 折扣管理机制 | 9 折让利润降 42.5%、7 折为负——因为市场费用、销售底薪、服务成本都固定 |
| 主产品不能免费；若做免费版需满足四条判据 | 价格=0 等于抽掉信息量最大的产品指标；to B 免费公式产出的是 100 家付费 + 9900 家不满 |
| 反对阶梯提成，改用固定比例月提成 + 运营四层递进 | 承认阶梯有效仍反对它——它会诱导藏单借单，不要和人性做斗争 |
| 组织架构设计七层框架：换 CRM 之前先体检 | IT 工具排在第 6 层——换系统解决不了第 2 层（责任与利益划分）的混乱 |
| 年度经营规划 6 阶段 15 步与 Breakdown（含健康度评估） | 目标必须 Breakdown 后才知合不合理：先认最难的老客续费，把增量空间留给自开拓 |
| 反对一站式：用数据视角而非功能视角做产品边界决策 | 做新模块会把你从「与同行对接」变成「替换同行产品」，凭空造敌人 |
| 卖多年单——饮鸩止渴 | 现金流增加了却是坏事：ARR 反而下降、CAC 可能占 ARR 120% 以上、续费机制失效 |
| 补贴式扩张：销售挣钱、公司不挣钱，补贴来的客户大多不续费 | 补贴买来的不是客户，是一份会被取消的续费期权 |
| 续费率不得剔除「自然死亡客户」：指标客观性三原则 | 任何让本部门指标变好看的口径调整请求，一律拒绝，改到下一级指标里单独分析 |
| 强激励必须配套强管控（否则文化变质） | 只关联过程指标必然掺水，连合同额回款也要防「把业绩堆到一个人头上」 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
