# GLOSSARY — 《SaaS创业路线图2.0》术语词典

> 本词典记录**作者本人的用法**，不是字典定义。凡标注「作者估计」的数字均为书中未给证据的个人推断，引用时须标注。

## 商业模式与产品

| 术语 | 作者的特定用法 | 出处 |
|---|---|---|
| 工具 SaaS | 只提供管理效率价值（帮客户省钱）。作者判断在国内「养不活公司」，天花板是营收过亿后年增 30%～50% | 主线1 第1节 |
| 商业 SaaS | 除工具价值外还提供「提高效率之外」的价值（增加营收、获金）。判据是「有没有数据增值价值」，只靠客情搭卖实物的不算 | 主线1 第1节 |
| 三重价值 | 工具价值 → 数据增值价值 → 平台（网络效应）价值；两次飞跃对应创业团队三级能力，必须逐层升级 | 主线1 第2节 |
| 外部合规需求 | 来自监管/买方/下游甲方的强制需求，是某品类真正的刚需来源（例：CRM 在欧美的隐藏刚需是防行贿留痕） | 序章 第1节 |
| SaaS 1.0 / 2.0 | 1.0 = 硅谷经典订阅模式（标准化、低服务）；2.0 = 中国本地化版本（更多人工服务、行业化、与平台共生）。本书主张必须走 2.0 | 序章 / 主线1 |
| 微创新「一根针捅破天」 | 聚焦单点做深而非铺功能面，是在中国做出差异化产品的路径 | 主线1 |
| 连环刀 | 轻产品（≤5 万）开路 → Upsell 增坐席 → Cross-Sell 加模块；5 万客单价成交周期 4～6 周、交付 1～3 天 | 主线1 第2节 |
| SaaS2C2B | 先在 C 端病毒式传播、再反向影响 B 端采购决策，是作者判断「是否互联网化」的市场侧特征 | 主线1 第2节 |
| 一站式（反例） | 把多个模块凑成「解决方案」。作者的判断依据是数据视角而非功能视角，见能力卡 say-no-to-all-in-one | 主线1 第2/4节 |

## 收入与指标

| 术语 | 作者的特定用法 | 出处 |
|---|---|---|
| ARR / MRR | 年度/月度经常性收入。作者强调只把可续的订阅收入计入，实施费与多年单预付不可混入 | 主线4 第1节 |
| 金额续费率 | （实续金额 + 增购金额）÷ 应续金额。作者定为 CSM 最关键 KPI，并提醒它含增购会掩盖基础续费问题，需另设不含增购的二级指标 | 主线1 第2节 |
| NDR（净收入留存） | 推荐算法 = 本年 12 月 MRR ÷ 上年 12 月 MRR（同一客群）。反映「客户价值的增减」，给投资人/CEO/财务看；用 ARR 算会失真 | 主线2 第4节 |
| 续费率（执行口径） | 反映「服务、续费工作的执行落地程度」，给 CSM 看。可控目标：客户数续约率 80%、金额续费率 95%（含增购） | 主线2 第4节 |
| 自然死亡客户 | 停止经营/业务转型的客户。作者裁定：计算续费率**不得**剔除，只能在流失原因分析里单列 | 主线3 第1节 |
| 活跃度 / 健康度 / 北极星指标 | 活跃率由系统自动算；健康度 = 活跃率 + 人为打分；北极星是单一维度、易获取、有先导性的客户侧指标，「可遇不可求」。定义活跃度的目的是**预测续费率**，统计单元必须是能做出续费决策的主体 | 主线2 第4节 |
| LTV / CAC / CAC Payback | LTV/CAC>3 是融资宽松期判据；融资断流后主判据换成 CAC Payback（回收周期）。CAC 占首单 40%～100%，中位数约 80%（作者估计） | 主线4 第1/3节 |
| UE（单位经济）闭环 | 第一个产品能盈利、用它的利润养第二个产品；营销环节的绝对底线是 LTV>CAC | 主线4 第4节 |
| 多年单 | 特指「签多年协议并一次付款」。签多年合同但按年付费与一年单无实质差别（作者承认这一点） | 主线4 第1节 / 终章 |

## 财务

| 术语 | 作者的特定用法 | 出处 |
|---|---|---|
| 主营业务成本 | 财报「销售成本」的改名（IaaS + 实施成本 + 服务团队成本，不含 CAC），类比制造业料工费。约占 ARR 20% | 主线4 第1节 |
| 毛利（G）/ 利润贡献（P）/ EBIT | G = R − C；P = G − CAC；EBIT = P − FF（产研 + 行政）。P 是作者自造的中间层，回答「扣掉获客成本后还剩多少可覆盖固定费用」 | 主线4 第3节 |
| 新购利润贡献 10% vs 续费增购 60% | 结构性的双链路：ARR 扣约 20% 主营成本再扣约 70% CAC，新购只剩 10%；续费+增购扣同样成本后可达 60% | 主线4 第1节 |
| ONPV（经营净现值） | 作者版 NPV：40 年存续、7% 折现、以经营参数为自变量跑单变量敏感性；只测算第一重（工具）价值。结论：续费率每变 1% 影响公司价值 5～17 倍 | 主线4 第2节 |
| 业财一体损益表 | 以权责发生制损益表为底板的三层表，沿新老客户/客户来源/产品/行业四维下钻；费用按**投入工时**而非产出结果分摊 | 主线4 第3节 |
| 人效 | 团队人均营收。作者把它从结果指标升为**战略自变量**：先定目标再倒推做法。中国 SaaS 平均约 30 万元/人（作者估计），头部 40–80 万元 | 主线4 第3节 |
| 生态位 | 由人效目标决定的业务边界：80 万人效的公司不做定制（做产品/PaaS），30 万人效是代理商/SI 的位置，靠无法标准化的本地服务建护城河 | 主线4 第3节 |
| PS 倍数 | 各轮参考：A 轮 30 倍、B 轮 20 倍、C 轮 15 倍、上市 12 倍；2022 年二级市场已跌到 8～10 倍。**2026 年不可直接引用** | 主线4 第4节 |

## 组织与业务

| 术语 | 作者的特定用法 | 出处 |
|---|---|---|
| L2C | 线索到回款的完整链路，也是组织架构设计的横轴：市场部管前半段（有效线索数），销售部管后半段（转化回款） | 主线3 第1节 |
| SDR | 只做初次联络与线索分类分级、**不负责成交**；建议放市场部（输出 MQL 的部门要与转化部门分开） | 主线2 第1节 |
| MDR | 市场开发代表，用于清洗低质量线索（作者建议在低客单价场景使用） | 序章 第1节 |
| CSM / 客户成功部 | 主动服务（区别于客服热线的被动应答），对「活跃且健康使用」负责，是唯一对续费率负责的部门；容量 = ARR 200 万～500 万元 | 主线3 第1节 |
| 无标准，不复制 / 无文字，不管理 | 没有标准 SOP 不许扩团队；任何销售动作必须沉淀成文字稿才能跨区域复用（客单价 1 万～4 万元的首访稿约 5000 字） | 主线2 第3节 |
| 价格位 | 某领域各厂商「人·年费用」形成的分层区间；是判断公司优劣的黄金标尺，且一旦确定基本不可逆 | 主线2 第1节 |
| 藏单 / 借单 | 阶梯提成诱导出的作弊：本月上不了高台阶就把单藏到下月；把单「借」给已上更高台阶的同事 | 主线2 第3节 |
| 知识—认知—共识 | 知识 = 说得出的道理；认知 = 压力情境下仍照做（9 月底目标完不成时还坚持不卖多年单）；共识 = 团队的认知一致 | 主线3 第3节 |
| 鸿沟理论 | 借自杰弗里·摩尔《跨越鸿沟》，作者把 SaaS 创业五阶段（创意/验证/营销/扩张/效率）与之结合：不同阶段的主要目标、方法与资源侧重不同 | 全书底层逻辑 |
| 三个复制 | 销售规模化的复制对象：客户（ICP）复制、销售人才复制、销售管理者复制 | 主线2 第3节 |
